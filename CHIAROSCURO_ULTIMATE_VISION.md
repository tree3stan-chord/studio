# CHIAROSCURO: THE ULTIMATE SOUNDSCAPE BLENDER
*From boring blob viewer to mind-bending sonic playground*

## CORE VISION
Transform incoming audio into a living, breathing visual organism that users can sculpt, stretch, and warp in real-time to create otherworldly soundscapes.

## THE PROBLEMS WITH CURRENT VERSION
- Blobs just sit there pulsing - no real life
- Synth notes don't sustain properly
- Dragging barely affects the sound
- Click-to-tone is underwhelming
- No sense of sonic exploration
- Missing the "wow" factor

## THE NEW CHIAROSCURO

### 1. VISUAL TRANSFORMATION
**From Static Blobs → Living Sound Organism**

#### The Frequency Ocean
- Replace discrete blobs with a **fluid field** of interconnected frequency bands
- Think: Ferrofluid responding to magnets, but for sound
- Continuous morphing surface with peaks and valleys representing frequency energy
- Color gradients flow between frequencies like northern lights
- Particle systems emanate from high-energy zones

#### Visual Modes (Cycle with Tab)
1. **Liquid Mode**: Fluid simulation where sound creates ripples and waves
2. **Crystal Mode**: Geometric crystalline structures that grow/shrink with frequency
3. **Particle Storm**: Thousands of particles forming patterns based on spectral content
4. **Neural Network**: Connected nodes pulsing with audio energy
5. **Fractal Mode**: Recursive patterns that evolve with sound

### 2. INTERACTION MATRIX

#### Click Actions
- **Click**: Spawn a **sonic well** - gravitational point that attracts and warps nearby frequencies
- **Double-click**: Create a **frequency mirror** - reflects and inverts frequencies around that point
- **Right-click**: Drop a **temporal anchor** - locks that frequency band in a time loop

#### Drag Interactions
- **Normal Drag**: **Frequency painting** - smear frequencies across the spectrum
- **Shift+Drag**: **Time stretching** - horizontal = stretch factor (1x-100x!), vertical = grain size
- **Alt+Drag**: **Harmonic generation** - create overtones and subharmonics
- **Ctrl+Drag**: **Spectral filtering** - carve out frequency ranges with gesture
- **Shift+Alt+Drag**: **Phase vocoding** - separate amplitude from phase, warp independently

#### Keyboard Synth Overhaul
- **Hold for sustain** (currently broken - needs fixing)
- **Velocity from key press speed**
- Each note spawns a **resonator** that captures and loops incoming audio at that frequency
- **Chord detection** - special visual effects for harmonic combinations

#### Modifier Keys
- **Space (hold)**: **Freeze mode** - capture current audio state, manipulate frozen spectrum
- **Q/W/E/R**: Quick switch between paulstretch variations (classic/smooth/extreme/glitch)
- **A/S/D/F**: Apply effects (reverb/delay/distortion/filter)
- **Z/X/C/V**: Time signatures (1/4, 1/8, 1/16, triplets) for rhythmic stretching

### 3. AUDIO PROCESSING PIPELINE

#### Multi-Layer Paulstretch Engine
```
Input Audio → FFT Analysis → 24 Frequency Bands →
    ↓
[Per-Band Processing]
    - Independent time stretching (1x - 100x)
    - Grain size modulation
    - Phase randomization
    - Amplitude envelope shaping
    ↓
[Cross-Band Effects]
    - Frequency bleeding (bands influence neighbors)
    - Harmonic coupling (octave relationships)
    - Formant preservation/destruction
    ↓
[Global Effects Chain]
    - Convolution reverb (spaces: cathedral/cave/space/underwater)
    - Feedback delay network
    - Spectral freeze/smear
    - Ring modulation
    - Granular clouds
    ↓
Output Audio
```

#### Sonic Features
1. **Spectral Morphing**: Smoothly interpolate between input spectrum and generated spectrum
2. **Frequency Feedback Loops**: Route output back through specific bands
3. **Temporal Smearing**: Blur events across time
4. **Harmonic Excitation**: Generate related frequencies from strong input bands
5. **Chaos Modulation**: Add controlled randomness to parameters
